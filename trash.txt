We now want to print the expected log likelihood histogram. Thus we need to find out its distribution.<br>
Here we handwavy show, that $\prod_i^d x_i \sim N(0, \frac{1}{d})$ for $x_i \sim N(0,1)$.<br>
Our prior distribution over the latent vector $z := \text{model}(x)$ is a multivariate Gaussian of the form $N_d(0,1)$.<br>
As all $z_i$ are assumed to be i.i.d. we can write them as $\prod_i^d p_i(z_i)$ with $p_i(z_i) \sim N(0,1)$.<br><br>
When $x \sim N(0,\sigma_1^2)$ and $ y \sim N(0,\sigma_2^2)$ then $xy \sim N(0, \frac{ \sigma_1^2 \sigma_2^2 }{\sigma_1^2 + \sigma_2^2})$. <br>
(See https://ccrma.stanford.edu/~jos/sasp/Product_Two_Gaussian_PDFs.html ) <br>
If $\sigma_1^2 = \sigma_2^2 = 1$ then $xy \sim N(0, \frac{1}{2})$.<br>
Now for any $a_i \sim (0, \frac{1}{d})$ and $x \sim N(0,1)$ it can be seen that $a_i x \sim (0, \frac{1}{i+1})$.<br>
Thus $\prod_i^d p_i(z_i) \sim N(0, \frac{1}{d})$.<br>

def compute_probs(data, n=10): 
    h, e = np.histogram(data, n)
    p = h/data.shape[0]
    return e, p

def support_intersection(p, q): 
    sup_int = (list(filter(
                lambda x: (x[0]!=0) & (x[1]!=0), zip(p, q) )))
    
    return sup_int

def get_probs(list_of_tuples): 
    p = np.array([p[0] for p in list_of_tuples])
    q = np.array([p[1] for p in list_of_tuples])
    return p, q

def kl_divergence(p, q): 
    return np.sum(p*np.log(p/q))

def js_divergence(p, q):
    m = (1./2.)*(p + q)
    return (1./2.)*kl_divergence(p, m) + (1./2.)*kl_divergence(q, m)

def compute_kl_divergence_2(train_sample, test_sample, n_bins=20): 
    """
    Computes the KL Divergence using the support 
    intersection between two different samples
    """
    e, p = compute_probs(train_sample, n=n_bins)
    _, q = compute_probs(test_sample, n=e)

    list_of_tuples = support_intersection(p, q)
    p, q = get_probs(list_of_tuples)
    
    return kl_divergence(p, q)

def compute_kl_via_ecdf(p_data, q_data):
    # http://www.tsc.uc3m.es/~fernando/bare_conf3.pdf
    dx = np.diff(np.sort(np.unique(p_data)))
    dy = np.diff(np.sort(np.unique(q_data)))
    ex, ey = min(dx), min(dy)
    e = min(ex, ey) / 2
    P = ECDF(p_data)
    Q = ECDF(q_data)
    
    x = p_data
    q_diff = np.array(Q(x) - Q(x-e))
    p_diff = np.array(P(x) - P(x-e))
    
    #print(q_diff)
    #print(q_diff > 0)
    print(np.sum(q_diff > 0))
    erase_idx = q_diff > 0
    q_diff = q_diff[erase_idx]
    p_diff = p_diff[erase_idx]
    
    if len(p_diff) == 0 or len(q_diff) == 0:
        return -1
    
    KL = np.mean( np.log(p_diff) - np.log(q_diff) )
    return KL

def run_lengths(X):
    
    lengths = []
    
    # note that the first char will automatically get a +1
    current_length = 0
    a = X[0]
    for x in X:
        if x == a:
            current_length += 1
        else:
            lengths.append(current_length)
            a = x
            current_length = 1
            
    lengths.append(current_length)
    
    return lengths

$F$ is an unknown distribution.\\
$[X, Y]$ is in the data space.\\
"$\rightarrow$" means one coupling layer and we will go towards the latent space. \\
Latent space will have a normal distribution as prior.\\
$M$, is a scaling number with $M \gg c$ (denoted as "scaler" in the code)\\ 
and $P(|X| > c, |Y| > c) > \delta/100$ (i.e. this procedure should work around $\delta$\% of the time).


\begin{align*}
\begin{bmatrix}
	X\\Y
\end{bmatrix}
\rightarrow	&\;\;\text{// Initialisation}
\\
\begin{bmatrix}
	X\\Y + M\cdot X
\end{bmatrix}
\rightarrow &\;\;\text{// Store X on top of Y by making it a really big number.}
\\
\begin{bmatrix}
	X-(Y+M\cdot X) / M\\Y + M\cdot X
\end{bmatrix}
=
\begin{bmatrix}
	-Y / M\\Y + M\cdot X
\end{bmatrix}
\rightarrow &\;\;\text{// Remove X from the upper entry. }
\\
&\;\; \text{// Now the upper entry will contain a really small number.}
\\
\begin{bmatrix}
	-Y / M\\Y + M\cdot X
\end{bmatrix}
\rightarrow &\;\;\text{//do nothing layer}
\\
\begin{bmatrix}
	 Y + M \cdot X - Y / M\\Y + M\cdot X
\end{bmatrix} 
=
\underbrace{\begin{bmatrix}
(1-1/M)Y + MX\\Y + MX
\end{bmatrix}}_\Lambda
= 
&\;\;\text{// add the bottom entry to the top. }
\\ &\;\; \text{// Now both entries have approximately the same value }
\\ &\;\; \text{// except for a small the error -Y/M.}\\
\begin{bmatrix}
X_5\\ Y_5
\end{bmatrix} \rightarrow& \text{We now apply the loop that shrinks this distribution}\\
& \text{close to 0.}\\

\begin{bmatrix}
X_5\\ Y_5 - X_5/2
\end{bmatrix} =& \\
\begin{bmatrix}

\end{bmatrix}

\begin{bmatrix}
	(1-1/M)Y + MX\\1/2(1+1/M) Y + (M/2) X

from numpy import arange, array, bincount, ndarray, ones, where
from numpy.random import seed, random, randint

class WalkerRandomSampling(object):
    # code from:
    # https://gist.github.com/ntamas/1109133/30362d4a91cfadc5ab69c23c63705b919a31c8a9
    
    """Walker's alias method for random objects with different probablities.
    
    Based on the implementation of Denis Bzowy at the following URL:
    http://code.activestate.com/recipes/576564-walkers-alias-method-for-random-objects-with-diffe/
    """
    
    def __init__(self, weights, keys=None):
        """Builds the Walker tables ``prob`` and ``inx`` for calls to `random()`.
        The weights (a list or tuple or iterable) can be in any order and they
        do not even have to sum to 1."""
        n = self.n = len(weights)
        if keys is None:
            self.keys = keys
        else:
            self.keys = array(keys)

        if isinstance(weights, (list, tuple)):
            weights = array(weights, dtype=float)
        elif isinstance(weights, ndarray):
            if weights.dtype != float:
                weights = weights.astype(float)
        else:
            weights = array(list(weights), dtype=float)

        if weights.ndim != 1:
            raise ValueError("weights must be a vector")

        weights = weights * n / weights.sum()

        inx = -ones(n, dtype=int)
        short = where(weights < 1)[0].tolist()
        long = where(weights > 1)[0].tolist()
        while short and long:
            j = short.pop()
            k = long[-1]

            inx[j] = k
            weights[k] -= (1 - weights[j])
            if weights[k] < 1:
                short.append( k )
                long.pop()

        self.prob = weights
        self.inx = inx

    def random(self, count=None):
        """Returns a given number of random integers or keys, with probabilities
        being proportional to the weights supplied in the constructor.
        When `count` is ``None``, returns a single integer or key, otherwise
        returns a NumPy array with a length given in `count`.
        """
        if count is None:
            u = random()
            j = randint(self.n)
            k = j if u <= self.prob[j] else self.inx[j]
            return self.keys[k] if self.keys is not None else k

        u = random(count)
        j = randint(self.n, size=count)
        k = where(u <= self.prob[j], j, self.inx[j])
        return self.keys[k] if self.keys is not None else k

def compute_average_volume_change_2(volumes):
    """computes the average log volume according to Davids reformulation """
    a = (-volumes).max()
    N = len(volumes)
    # Vol in original space is logged
    # log sum exp with the maximal a
    # exp * (a + log (1/N sum_i exp( -V(x_i) - a ) ))
    avg_log_volume = - (a + torch.log(torch.sum(torch.exp(-volumes - a))) - np.log(N))
    return avg_log_volume

def reduce_dim_keep_length_and_angle(Z):
    ancat = Z[:, 0]  # x
    cat = Z[:, 1]  # y
    
    angles = [np.arctan2(Z[:, i], Z[:, i+1]) for i in range(USED_DIMENSION-1)]

    sin = np.mean(np.sin(angles), axis=1)
    cos = np.mean(np.cos(angles), axis=1)
    angles = np.arctan2(sin, cos)

    X = length * np.cos(angles)
    Y = length * np.sin(angles)
    return X, Y

def remove_quantile_old(X, Y, alpha):
    # length is the distance to the center. We will use this to cut off data

    left_Y, right_Y = quantile_finder(Y, alpha)

We have shown that for a fixed manifold dimensionality and a none-curved embedding 
additional data dimensionality do not render the state density harder to learn.
Additionally, the lower the dimensional ratio, the closer the state density of the data to the prior (up to translation).
This can be seen by the random variable that defines the state density by its pdf.
Note that we use rotation for embedding and that the state density of a random variable and its rotated version are the same.
Thus we can look at the none-rotated random variable of the data $[L_1, ..., L_d, N_{d+1}, ..., N_D] =: X$ with $L_i := M_i + N_i$.

\log p(X)&= \log p([L_1, ..., L_d, N_{d+1}, ..., N_D])\\
&= \log p(L_1, ..., L_d, N_{d+1}, ..., N_D) \\
&= \sum_{i=1}^{d} \log p(L_i| L_{i+1:d}) + \sum_{j=d}^{D} \log p(N_j)

\subsubsection{A Metric for the Density of States Difference} \label{metric}
We will derive a metric and a representation of this metric to later show if the DoS was learned properly.


If we want to find the distance in DoS for two random vectors $X$ and $Y$ (with $\dim(X) = \dim(Y) = D$)
we should take account their dimensionality. 
Otherwise we could accumulate small errors even though the DoS for every random variable of the vectors $X$ and $Y$ 
is almost the same ($\text{DoS}(X_i) \approx \text{DoS}(Y_i)$).\\
Thus our metric normalizes the DoS with its dimension ($\frac{\log p(X)}{\dim(X)}$).

\noindent NICE can not change the shape of the DoS, thus to figure out if NICE has approximated 
the DoS as good as possible, we are interested in where the mean of the DoS is.
Thus we compute the DoS distance $\DosDist$ between two random vectors $X$ and $Y$ like

\begin{equation}
	\left| \mathds{E}_{x \sim X}\left[ \frac{\log p_x(x)}{\dim} \right] - \mathds{E}_{y \sim Y}\left[ \frac{\log p_y(y)}{\dim} \right] \right| =: \DosDist(X, Y)
\end{equation}
Which is equivalent to the square root of the maximum mean discrepancy ($\MMDDoS$) between $\frac{\log p_x(X)}{\dim}$ and $\frac{\log p_y(Y)}{\dim}$.
(The square root will make computation easier later on.)\\

\noindent We can represent a fixed distance $d_1$ as the $\DosDist$ between $\N(0, 1)$ and $\N(0, \sigma_{d_1}^2)$ 
with
\begin{align}
	\sigma_{d_1}^2 &= \exp(2 \cdot d_1).
\end{align}

\noindent An informal proof can be found in Appendix \ref{appendos}.
